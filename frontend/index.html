Enterprise Production Deployment Guide

1. Production Launch Command

# Run script from project root:
python run.py

2. Automated DB Table Seeding

The system automatically detects if backend/database.db exists. On first launch, init_db() creates all 6 core tables and seed() populates initial mock registrations, sponsors, and incidents.

3. Offline AI Deterministic Engine

All AI rules in event_intelligence_service.py and agent_orchestrator.py run locally using zero-dependency Python logic, ensuring zero latency delays and total offline reliability during live events.
